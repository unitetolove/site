What we’re building.

The Map shows this work organized by city issue. This page shows the same work organized the other way — by project. It is a public-safe status report drawn from the full internal project list, filtered to what can honestly be shown: what exists, what state it’s in, and what is only proposed so far. Nothing below claims to be finished when it isn’t. Some internal work is left off this page entirely — not because it’s hidden, but because it isn’t resident-facing content (internal operations, anything evaluating named individuals, anything still under legal review). This page updates as things change; it is not a promise of dates.

We use the same three-word status vocabulary here as everywhere else on this site: Linked (published, click through and read it), In verification (drafted, going through independent checking, not published yet), and Proposed / coming (planned or scoped, not built yet). If a project below has no link, there is no live page for it yet — that is stated plainly rather than implied.

In progress right now

A closer look at what is actively on the workbench — as of July 28, 2026. One extra status word applies in this section: In build means being actively worked on right now, before the verification stage. Everything here is stated at its real stage; nothing below is a promise of a date.

The candidate landscape

Ward-by-ward races and registered-candidate counts, drawn from public records only, so anyone can see where seats lack a real contest. This is the highest-priority research lane right now for one reason: the deadline to file as a candidate is August 21, 2026, at 2:00 p.m. — and more good people should be in these races. If that could be you, start at the Run page. In build.

Ward profiles

A civic profile for each of the city’s 25 wards, grounded in census data and other cited public sources. First version live: a 25-ward summary table from the 2021 Census, sourced and dated; profiles grow from here.

Permaculture 3.0

The design philosophy underneath much of this project: a pattern language for how people, places, and living systems can take care of one another, applied to a whole city. It is written; it is now being prepared for publication here, and the intention is to share it in full. In build.

The vision, told for different readers

One vision, one set of facts — rendered separately for different audiences. The general-public version is live now on the full-vision page. A version written for newcomers is approved and on its way; letters addressed to community organizations and to candidates are in draft. Live (first door) / In build (the rest).

Sign-up & the welcome count

A single, simple way to say “count me in.” The join door is live now, with email as the courier to start; direct submission on the page and a public welcome count are being built next. The count will open once the first few dozen have signed on — honest numbers only, from day one. Live (the door) / In build (count & direct submission).

The newsletter

An occasional-news channel for short, sourced updates when there is something real to say — being set up now. Receipts remain the primary promise; a newsletter is a courier, not the product. In build.

Free Toronto Resource Atlas

The atlas of verified free and low-cost resources for residents is live and still growing; verification continues entry by entry on the newest additions. Live — verification continuing.

State of the election

A running, cited snapshot of where the 2026 municipal race stands, refreshed as the August 21 nomination deadline approaches. Built internally; its public page is part of this same push. In build.

The verification wave

The remaining plain-language explainers, discussion guides, and platform planks are moving through independent checking category by category — each one is published only when it clears. In verification.

What this page leaves out, on purpose

Some internal work is structurally absent from this page — not summarized, not counted, not hinted at. That includes anything evaluating named individuals or organizations, any operational outreach data (contact lists, send lists), internal infrastructure that has no resident-facing purpose, anything still waiting on legal review, and a small number of items that are deliberately parked and not resurfacing on any schedule. We don’t publish a list of what those are — a list would just be a map to the same information by another name. If something you’d expect to see here is missing, the honest answer is one of: not built yet, in verification now, or it was never going to be shown here and we’re not going to pretend otherwise with a hinting gap.

This is a transparency page, not a pitch. There is no team to join and no donation ask anywhere on this site. If you find something here that’s wrong or out of date, tell us: corrections.
