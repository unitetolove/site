Toronto's problems — start here

What this project is, how it asks questions, and how to help: Toronto's Questions — an open research project for a city deciding its future.

Start from a problem. The questions are set; over the coming weeks the research waves run through them in rank order, and these pages update as answers land. Each file below gives one lived problem its full treatment: what the problem is (framing + receipts), what we're asking (research questions organized primary → clusters → subsidiary/tertiary, every harvested question carrying its source tag), what we already have (the evidence shelf: backgrounder · leaf · brief · card · deep surfaces), and what's unexplored. No internal taxonomy needed to navigate — the problem is the front door.

The machinery under the master briefing

  1. PROBLEM REGISTER — what are Toronto and Torontonians' problems? (one of this library's own project records) — the framing of record. 55 entries (all 68 problems incl. compact combined headers): statement, who's hit, scale with receipts, levers by government level, gaps named. Every spine file's §1 distills from here and links back.
  2. THE RANKED LIST — Toronto & Torontonians’ problems, ranked — the order. 6-axis scores, 4 perspectives, tiers, entanglement chains — the ratified working order.
  3. DECISIONS BEFORE 2030 — the full inventory (Phase C, one of this library's own project records) — the clock. Decisions scheduled inside the 2026–2030 term, mapped to the problems they lock in.
  4. QUESTION_HARVEST.csv — the question corpus. 1,234 rows machine-harvested from 18 program question banks + the register's gap cells, with source file/ID per row. The master briefing files organize 442 of these (machine-counted) and raise 144 new; the remainder stay in their program banks (program-design questions, not problem questions).
  5. SHELF_MAP.csv — artifact → problem map. 149 topic slugs × problems, many-to-many (192 rows); each slug = a backgrounder/leaf/brief/card set. Orphans named honestly in Shelf Map — Orphans (2026-08-11); SHELF_STEMS.csv is the raw stem inventory.

Known shelf gaps (machine-derived, named not hidden): J1 financial rails · X13 social-services navigation · H3 school-board governance · X12 demographic whiplash have NO artifact serving them.

Solution Suite = separate future intake, fired per problem in ratified rank order. Receipt tiers everywhere: a claim checked against its primary source and formally registered · [URL] ⚠️ still being checked before publish · [corpus] repo file. History (prior editions, pass records): not published.

Source tags like (homes HM12) mark questions carried from the project's own question banks (QUESTION_HARVEST.csv); untagged questions were raised in the 2026-08-11 rewrite.
