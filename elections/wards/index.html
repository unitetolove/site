Ward Math Cards — Toronto 2026

This is the raw math of every Toronto council race, one card per ward — the 2022 baseline margin, who has filed to run in 2026, and when each of them registered, built strictly from this project’s own receipted election dataset. Ward-by-ward turnout is honestly not held here: the only turnout figure on file is citywide, and each card says so rather than implying a precision this dataset doesn’t have. Every filed candidate is listed once, alphabetically by surname, with no ranking or characterization — that’s the receipts culture this whole project runs on.

Provisional — data as of 2026-08-05; nominations close August 21, 2026. Filed-candidate counts and competitiveness tiers will change as more candidates register; each ward page carries its own receipt with the exact source and date.

Read next: the whole field, honestly mapped — the standing baseline these cards sit inside — and the Platform Baseline, every candidate’s published platform measured for breadth, depth and quality. Back up to State of the Election for the full biweekly record.
