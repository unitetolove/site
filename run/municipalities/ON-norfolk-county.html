How to correct an error

This page is generated mechanically from municipalities.csv / races.csv / candidates.csv; it is not hand-edited. If anything above is wrong, out of date, or missing:

  1. Check the candidate's own current public campaign site or social account, and the municipality's own live candidate list (linked above) — those are the primary sources this page draws from.
  2. Corrections should point to a public, verifiable source (a candidate's own site, a clerk record, an official results document) — unsourced claims about any candidate are not taken.
  3. This page should be regenerated from the source CSVs after any correction, not edited in place.
