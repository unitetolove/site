Tribe Map
This is an organization-level directory only — organizations and public communities, never people (D-153). Individual member/moderator/participant data is never published here. Sizes under 1,000 are not shown, so a count can never be small enough to identify who's inside a community. Roughly two-thirds of the rows below are listing-only: a community was found to exist, but its current size/activity was not independently confirmed this pass — those carry a ⚠️ VERIFY mark rather than being silently presented as checked. Free-text notes, moderation/activity signals, and anything else that could read as a “how to work this community” guide were deliberately excluded before this page was built — only name, public URL, self-declared scope/topic, and confirmation status are shown.

The Tribe Map — organizations & public communities

A directory of Toronto/GTA/Ontario public communities on Reddit, Facebook, Instagram, Discord, and YouTube — neighbourhood groups, mutual aid, diaspora communities, hobby/sport clubs, and city/regional hubs. Organizations only, at the level D-153 authorizes: name, public URL, self-declared scope, and whether we could confirm it. No moderator names, no member lists, no per-person data of any kind.

Census window: 2026-07-27 to 2026-07-28 · next scheduled refresh: 2026-10-27 (quarterly, per the census's own refresh guidance).

What "confirmed" means, per source

Reddit: confirmed = we visited the subreddit and recorded a verification date. Listing-only = found via subreddit search only, never independently visited.

Facebook/Instagram/Discord/YouTube: these four platforms are largely login-walled to outside research, so "confirmed" here is weaker by construction — it means a search result surfaced the platform's own stated size at least once ("confirmed listing, no size" means the community's existence was corroborated in a directory listing, e.g. Disboard for Discord, without a size figure). Listing-only means the community's existence rests on a single search-result snippet, never independently corroborated. See each page's own per-row marks.
