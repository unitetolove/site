## THE O IS A SLOT

Every composed mark carries `<g id="o-slot">` centred on the **registration
point**, sized to the **safe area**:

| base | registration point (cx, cy) | safe radius |
|---|---|---|
| master (viewBox 0 0 3879 900) | 2205, 349 | 264 |
| poster (viewBox 0 0 4212 1071) | 2492, 415 | 296 |

Swapping the O is a file swap, not surgery:

```
python3 logo_compose.py --lettering master --o fine    --out mark.svg
python3 logo_compose.py --lettering poster --o empty   --out poster_mark.svg
python3 logo_compose.py --lettering master --o my-drawing.svg --out mine.svg
```

Any SVG passed to `--o` is auto-scaled to the safe area and centred on the
registration point. That last line is the whole point: draw anything in a free
SVG editor, and the mark is yours while still reading as ours. The ring always
prints — the ring is the letter; only the inside is yours.

Variants: `fine` (canonical) · `stencil` (knife-cuttable, small sizes, spray)
· `empty` (POSTER_SYSTEM §5 poster default — colour it in) · `frame` (dashed
"yours to fill").

## Rules that ride every use

- One colour; must survive a bad photocopier and a 1-bit threshold (tested at
  build: 2026-08-06 renders in [`../../../strategy/site/logo_system/b3_previews/`](../../../strategy/site/logo_system/b3_previews/)).
- Use fine O at large sizes, stencil O below ~3 cm — fine lines fill in.
- Stencil cutting: the ring needs 3–4 bridge tabs or the centre falls out;
  the stencil sheets in the print pack carry them pre-marked.
- Alt text, every digital use: "uniteTOlove — THE TRUE NORTH STRONG AND FREE"
  (built into every SVG as `<title>`/`aria-label`).
- Identity firewall: no personal names in files, filenames, or metadata — ever.
