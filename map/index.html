How to read this grid

Every deliverable type in every category is one of four things. We use the same four words everywhere on this site, so once you know them here, you know them everywhere:

  • Linked — independently verified and published. Click through and read it now.
  • In verification — drafted, and going through the same independent check every linked page already passed. Not published yet because it hasn’t cleared that check — not because anyone is hiding it.
  • Proposed / coming — scoped or chartered, not yet built. An honest line about what’s planned, nothing more.
  • (blank) — nothing here. We do not fill empty cells with placeholder text to make the grid look fuller than it is. A blank cell means exactly what it looks like: this doesn’t exist yet, or isn’t part of the current plan.

A word on what “verified” means here, since we use it a lot: every fact-bearing claim in a linked page was checked against its original source independently before publication — not just written down and trusted. “In verification” pages have already been drafted against sources; they’re going through that same independent check now, and a small number have specific open items still being chased down (a source that wouldn’t load, a figure we couldn’t yet confirm elsewhere). We say so rather than quietly rounding up to “done.” The full method — the checks a page passes before it is published, and exactly what each status word promises — is on one page: How we verify.

What you will never find here

Some things are structurally absent from this site, on purpose, permanently — not “coming soon,” not a locked door with a sign on it, just genuinely not here. That includes anything evaluating named individuals, any operational outreach data (contact lists, send lists), and anything held for legal review before it can be shown to anyone. We don’t list what those are; a list would just be a map to the same information by another name. If a category or a deliverable type is missing above and you don’t see an explanation, the honest answer is one of: not built yet (see “proposed / coming”), in verification now, or it was never going to be public and we’re not going to pretend otherwise by leaving a hinting gap.

This page updates as things clear verification. It is not a promise of dates — only a promise that the status shown is the real one, checked, not aspirational.
