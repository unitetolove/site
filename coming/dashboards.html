Live Civic Dashboards

Public, live-data dashboards that would score the city against its own stated goals, using open civic data.

Real status, as of 2026-08-05: concept only. No dashboard exists yet, in any category, and none is currently under construction. There is no committed build timeline.

What does exist today, related but separate: a page describing planned public access to the datasets behind this site (Open Data & API) is staged on this site, not yet published. That is groundwork a dashboard would eventually draw on — it is not a dashboard itself, and no dashboard has been started.

The design intent, if and when this is built, is to keep the underlying data publicly owned, unlike past vendor-controlled “smart city” experiments elsewhere. This page will be updated, with a new date, when real work begins — not before.
